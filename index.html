🧹 Step 2: Data Cleaning & Preprocessing

Cleaning Techniques Applied

✓ Duplicate Removal

Systematically identified and removed duplicate employee records using Excel's Remove Duplicates feature, ensuring each employee appears only once in the dataset.

✓ Missing Value Handling

Addressed missing values through multiple strategies: removed records with critical missing data, filled predictable values based on patterns, and documented decisions for transparency.

✓ Data Type Standardization

Converted all columns to appropriate data types: dates to DATE format, numerical values to NUMBER format, text to TEXT format for consistency across the dataset.

✓ Text Normalization

Standardized text entries by trimming whitespace, converting to proper case, and ensuring consistent formatting for department names, job titles, and categories.

✓ Outlier Detection

Identified and reviewed potential outliers in salary, tenure, and performance metrics. Validated anomalies against business rules before deciding to keep or flag them.

✓ Date Consistency

Standardized all date fields to a consistent format (MM/DD/YYYY), verified date ranges for logical consistency (e.g., hire date before departure date).

⚙️ Step 3: Advanced Transformation with Power Query

Power Query Process Overview

Used Power Query to perform advanced ETL (Extract, Transform, Load) operations, enabling complex data transformations that would be difficult to manage in standard Excel.

Transformation Steps

1. Data Loading

Action: Imported cleaned Excel data into Power Query
Method: "Get Data" → Excel file → Select appropriate tables
Outcome: Connected data source for live refresh capability

2. Column Profiling

Action: Analyzed data profile for each column
Insights: Identified data distribution, unique values, null percentages
Benefit: Informed transformation decisions

3. Feature Engineering

Created calculated columns:

  • Tenure Categories: "New" (0-2 yrs), "Growing" (2-5 yrs), "Experienced" (5+ yrs)
  • Salary Bands: Entry-Level, Mid-Level, Senior, Executive
  • Age Groups: 20-30, 31-40, 41-50, 51+
  • Performance Levels: Low, Average, High, Exceptional
  • Risk Scores: Calculated based on multiple factors

4. Aggregations & Calculations

Computed key metrics:

  • Attrition rates by department, tenure, and age group
  • Average salary by position and department
  • Employee count and distribution metrics
  • Performance and satisfaction aggregations

5. Data Type Refinement

Action: Set appropriate data types for each column
Types Applied: Whole Number, Decimal, Text, Date, Currency
Result: Ensures correct calculations and formatting in Power BI

🔍 Step 6: Key Findings & Insights

Critical Discoveries

🔴 Early Tenure Risk: Employees within first 2 years show significantly higher attrition. This is the largest intervention opportunity through improved onboarding and career development.
💰 Compensation Gap: Strong inverse relationship between salary and retention. Below-market compensation drives higher attrition compared to industry benchmarks.
📊 Department Variation: Attrition rates vary significantly (15-35% range). Some departments require targeted interventions while others demonstrate best practices.
👥 Age Demographics: Younger employees (20-35) show higher attrition due to greater mobility and career flexibility.
😊 Satisfaction Impact: Job satisfaction is the strongest attrition predictor. 10-point satisfaction increase correlates with measurable retention improvements.
